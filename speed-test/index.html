    What is measured

    The page loads the newest game file from the play page and starts a race on The Suburbs directly, without going through the menus. The game runs with its own empty save, so your saved game is never read by the race and never changed. The page does read your saved settings once, only to report them.

    Real race: the game drives itself from the start line with its speed guard on, like normal play. Each second the page records the typical and slowest frame, the time the game spends thinking (update) and issuing drawing commands (draw), and what the speed guard did.

    Real cost per frame: the screen limits the game to one frame per refresh (60 FPS), so a frame that takes 4 ms and one that takes 15 ms both show as 16.7 ms. To see the real cost, the page freezes the race at the streetlights and draws 1, 2, 4, 8 and more copies of each frame until the computer falls behind, then divides. This is done at full sharpness, at picture size x1 and x0.5, with edge smoothing off, with the canvas look (the fallback the speed guard can switch to), and on Orchard Ring, which is seen from farther back and draws more (Full run: every track).

    Graphics card time: where the browser offers a graphics card timer (Chrome usually does, Firefox does not), the page reads it directly as well.

    Call count: for 60 frames the page counts every drawing call the game makes, and flags calls that make the browser wait for the graphics card; Firefox handles those slowly.
